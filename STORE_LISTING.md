# WhatStack — Professional Website Tech Stack Scan & Detector

Discover the technology architecture of any website in seconds. WhatStack is a high-performance browser extension that performs a deep **Stack Scan** to identify the frameworks, CMS, analytics, and hosting services powering the modern web.

### 🚀 Key Features
- **Deep Tech Detection**: Instantly identify React, Vue, Next.js, WordPress, and 100+ other technologies.
- **Signal Analysis**: Goes beyond the DOM by scanning HTTP response headers, global variables, and meta tags for maximum accuracy.
- **Clean Dashboard**: View results in a beautifully categorized UI—grouped by Frameworks, E-commerce, Analytics, and more.
- **Privacy First**: All detection logic runs locally on your machine. No data collection, no tracking.
- **Developer Optimized**: Built with Manifest V3 for zero impact on browser performance.

### 🔍 What can it detect?
WhatStack identifies a wide range of web technologies, including:
- **Frameworks**: React, Vue, Angular, Svelte, Next.js, Nuxt.js
- **CMS & E-commerce**: WordPress, Shopify, Webflow, Squarespace, Wix, Magento
- **Analytics & Marketing**: Google Analytics, Hotjar, Mixpanel, HubSpot
- **Hosting & Infrastructure**: Vercel, Netlify, Cloudflare, AWS

### 🛠️ How to use
1. Install WhatStack from the Chrome Web Store.
2. Visit any website you want to analyze.
3. Click the WhatStack icon in your toolbar to see the full technology breakdown.

Whether you're a developer, a designer, or a competitive researcher, WhatStack provides the market intelligence you need to stay ahead.
